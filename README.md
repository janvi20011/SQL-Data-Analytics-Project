
# SQL Data Analytics Project

## Project Overview

This project demonstrates a complete **SQL Data Analytics workflow**, starting with **Exploratory Data Analysis (EDA)** and progressing to **Advanced Analytics**.

The project focuses on exploring sales data, understanding customers and products, identifying trends and patterns, and generating meaningful business insights using SQL.

---

##  Project Objectives

- Explore and understand the database structure
- Analyze customer and product dimensions
- Examine important business measures
- Identify sales trends and patterns
- Rank top and bottom-performing products and customers
- Perform cumulative and performance analysis
- Segment data into meaningful groups
- Create analytical customer and product reports
